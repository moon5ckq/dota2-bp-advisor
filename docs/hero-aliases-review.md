# Dota2 英雄别名协作表

> 帮助完善英雄搜索别名，让搜索更准确。
> 请在"补充别名"列添加你知道的英雄叫法，用逗号分隔。

## 如何贡献
1. Fork 本仓库
2. 切换到 `hero-aliases` 分支
3. 编辑本文件，在对应英雄的"补充别名"列添加内容
4. 提交 Pull Request

## 别名类型说明
- 英文全名/缩写（如 Anti-Mage, AM）
- Dota1老叫法（如 骷髅王）
- 玩家俗称（如 胖子、飞机）
- 谐音梗（如 51=巫妖/巫医）
